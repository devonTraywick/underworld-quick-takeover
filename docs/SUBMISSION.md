# Underworld: Quick Takeover — submission package

## Concise description

**Underworld: Quick Takeover** is a 2–8 player browser strategy game about rival crime bosses fighting for a luxury-noir city. Across five fast rounds, every player negotiates in real time, secretly drafts an action card, deploys a hidden operation, and watches every move resolve together on the city map.

What makes Underworld distinctive is the tension between promises and power. Players can propose structured private deals, honor them for mutual rewards, or risk a costly Double Cross. Secret missions give every boss a different agenda, while simultaneous actions keep all players involved and make each cinematic reveal a shared moment.

To start, one player opens the public link, chooses a syndicate name, creates a private room, and shares its six-character code or invite link. Two to eight players join without accounts or downloads. The host selects Quick or Guided pacing and begins the takeover.

The game is fun because every round asks a compact social question: cooperate now, strike alone, or betray at exactly the right moment. Matches are short enough for an immediate rematch, but rotating draft priority, adaptive maps, private information, and rival personalities make each table play differently.

## Start instructions

1. Visit https://underworld-quick-takeover.vercel.app.
2. Select **Enable Sound** if desired, enter a syndicate name, and create a room.
3. Share the invite link or room code with 1–7 rivals.
4. Choose Quick or Guided pacing and select **Begin Takeover**.
5. Read the private mission briefing, then negotiate, draft, target, and reveal through five rounds.
